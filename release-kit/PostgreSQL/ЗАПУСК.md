# Только PostgreSQL — демонстрация базы AETHER

Здесь находятся только PostgreSQL, исходная схема AETHER и сценарии запуска. AEGIS, relay, Python и SQLite в этой папке отсутствуют. В схеме 16 таблиц; приватные аккаунты, сообщения, пароли и рабочие токены в релиз не включены.

## Запуск с основной Windows

Из корня распакованного архива в PowerShell:

```powershell
& '.\PostgreSQL\Start Database Sandbox.cmd'
```

Или откройте **Start Database Sandbox.cmd** двойным кликом в этой папке. Он запускает отдельную Windows Sandbox и внутри неё PostgreSQL с консолью, где автоматически показаны таблицы и их структура. На основной Windows ничего не устанавливается. Нужны уже доступная Windows Sandbox и около 4 ГБ свободной RAM.

## Запуск и остановка внутри гостевой Windows

На рабочем столе гостя будут **Start PostgreSQL** и **Stop PostgreSQL**. Команды PowerShell:

```powershell
& "$env:USERPROFILE\AEGIS-PostgreSQL-kit\Database\Start PostgreSQL.cmd"
& "$env:USERPROFILE\AEGIS-PostgreSQL-kit\Database\Stop PostgreSQL.cmd"
```

Для запуска без открытия консоли:

```powershell
& "$env:USERPROFILE\AEGIS-PostgreSQL-kit\Database\scripts\start-database.ps1" -NoConsole
```

Подключение внутри песочницы: **127.0.0.1:54331**, база **aether_demo**, пользователь **demo**. Пароль создаётся автоматически и защищён Windows DPAPI. Вводить его для готовой консоли не нужно. Сервер слушает только локальный адрес, службы Windows не создаются.

## Команды для показа преподавателю

В открытой консоли PostgreSQL:

```sql
\dt
\d users
\d messages
SELECT current_database(), current_user;
SELECT tablename FROM pg_tables WHERE schemaname = 'public' ORDER BY tablename;
```

Для демонстрации записи и чтения можно создать отдельную учебную таблицу:

```sql
CREATE SCHEMA IF NOT EXISTS presentation;
CREATE TABLE IF NOT EXISTS presentation.notes (id integer PRIMARY KEY, note text NOT NULL);
INSERT INTO presentation.notes VALUES (1, 'PostgreSQL works independently')
ON CONFLICT (id) DO UPDATE SET note = EXCLUDED.note;
SELECT * FROM presentation.notes;
```

После **Stop PostgreSQL** и **Start PostgreSQL** повторите последний `SELECT`: запись сохраняется. `\q` закрывает консоль, оставляя сервер запущенным.

Исходная схема находится в **data/aether.sql**, готовый обзор — в **sql/overview.sql**. Рабочие данные и логи находятся внутри гостя в **%LocalAppData%/AEGIS-PostgreSQL**. Повторный запуск использует существующие данные и не импортирует схему поверх них.

Полное закрытие Windows Sandbox удаляет гостевые рабочие данные. Исходная схема из архива остаётся, а новая сессия создаёт новую базу. Одновременно доступен один экземпляр Sandbox; запуск новой сессии из корня комплекта ещё не проверялся на другой Windows.
