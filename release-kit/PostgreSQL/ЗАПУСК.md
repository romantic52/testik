# Только PostgreSQL — демонстрация базы AETHER

Здесь только PostgreSQL 16, исходная схема AETHER (16 таблиц, без аккаунтов и сообщений) и скрипты. AEGIS, relay и Python этот комплект **не запускает**.

## Запуск

| Где | Как |
|---|---|
| В отдельной Windows Sandbox (ничего не ставится на основную Windows) | `Start Database Sandbox.cmd` |
| Прямо на этой Windows | `Database\Start PostgreSQL.cmd` |

Сервер слушает только `127.0.0.1:54331`. База `aether_demo`, пользователь `demo`. Пароль генерируется при первом запуске и хранится зашифрованным Windows DPAPI в `%LOCALAPPDATA%\AEGIS-PostgreSQL\credential.xml` — вводить его не нужно. Служб Windows комплект не создаёт.

## Кнопки в папке Database

| Файл | Что делает |
|---|---|
| `Start PostgreSQL.cmd` | запускает сервер (повторный запуск безопасен), при первом запуске импортирует схему, открывает консоль psql с обзором таблиц |
| `Stop PostgreSQL.cmd` | останавливает сервер, данные сохраняются |
| `Backup PostgreSQL.cmd` | делает резервную копию `aether_demo` в `Документы\AEGIS-PostgreSQL-backups\*.dump` и проверяет её |
| `Restore PostgreSQL.cmd` | восстанавливает последнюю копию в **новую** базу `aether_demo_restore_<время>`; рабочая база не перезаписывается |
| `Repair PostgreSQL.cmd` | если импорт схемы когда-то прервался: переименовывает неполную базу в `aether_demo_failed_<время>` (ничего не удаляет) и создаёт её заново |

## Команды для показа преподавателю (в консоли psql)

```sql
\dt
\d users
\d messages
SELECT current_database(), current_user, version();
SELECT tablename FROM pg_tables WHERE schemaname = 'public' ORDER BY tablename;

CREATE SCHEMA IF NOT EXISTS presentation;
CREATE TABLE IF NOT EXISTS presentation.notes (id integer PRIMARY KEY, note text NOT NULL);
INSERT INTO presentation.notes VALUES (1, 'PostgreSQL works independently')
ON CONFLICT (id) DO UPDATE SET note = EXCLUDED.note;
SELECT * FROM presentation.notes;
```

После `Stop PostgreSQL` и `Start PostgreSQL` последний `SELECT` возвращает ту же запись. `\q` закрывает консоль, сервер продолжает работать.

## Файлы

- Схема: `data\aether.sql`, обзор: `sql\overview.sql`.
- Данные и логи: `%LOCALAPPDATA%\AEGIS-PostgreSQL\pgdata` и `...\logs`.
- В песочнице данные живут до закрытия её окна; для сохранения сделай Backup и скопируй `.dump` наружу.
