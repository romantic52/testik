# AEGIS SOC 0.7.0 — запуск полного проекта

В папке: **AEGIS** (готовая программа, .NET встроен), **AETHER-LAN** (настоящий relay чата AETHER + PostgreSQL + Python), **Source** (исходники), **Evidence** (результаты проверок).

## Вариант 1. Изолированно, в Windows Sandbox (рекомендуется для демонстрации)

Двойной клик **Start Sandbox.cmd**. Откроется гостевая Windows, в ней:

1. сразу запускается AEGIS и открывается окно мониторинга (`http://127.0.0.1:8765`);
2. в фоне поднимается relay AETHER. Если relay не поднялся — мониторинг всё равно работает, чат покажет «нет связи», причина — в `Desktop\AEGIS-results`.

На рабочем столе гостя: **Start AEGIS**, **Stop AEGIS**, **Diagnose AEGIS**, **Start AETHER LAN**, **Stop AETHER LAN**.

Windows Sandbox одна на компьютер. При закрытии окна песочницы всё её содержимое удаляется.

## Вариант 2. Обычная Windows (без песочницы)

Мониторинг, лаборатория, инциденты, отчёты — в AEGIS. Чат — через локальный relay:

| Действие | Что нажать |
|---|---|
| Запуск | `AEGIS\Start AEGIS.cmd` |
| Остановка | `AEGIS\Stop AEGIS.cmd` |
| Диагностика | `AEGIS\Diagnose AEGIS.cmd` — пишет, какая версия отвечает на порту 8765, откуда она запущена, где данные, последние ошибки |
| Служба Windows (автозапуск) | `AEGIS\install-service.bat` — сам запросит права администратора, остановит консольный AEGIS и перенесёт данные; удаление — `uninstall-service.bat` |

Данные (инциденты, аудит, история графиков, журнал соединений, входы, настройки, логи): обычный запуск — `%LOCALAPPDATA%\AEGIS`, служба — `%ProgramData%\AEGIS`. При обновлении и переустановке **не удаляются**. Чтобы удалить программу — останови её и удали папку; данные — дополнительно удали эти каталоги.

**Зачем служба.** Только с правами службы AEGIS читает журнал безопасности Windows (входы, подбор пароля) и считает трафик по каждому соединению и процессу. Без службы эти разделы честно пишут, чего не хватает.

**Температура CPU.** Библиотека датчиков LibreHardwareMonitor читает процессор и материнскую плату через драйвер **PawnIO** (https://pawnio.eu). Без него температура CPU показывается как «недоступна» — даже с правами администратора. Видеокарты NVIDIA/AMD читаются и без драйвера.

### Чат на этом компьютере

1. `AETHER-LAN\Start AETHER Local.cmd` — поднимает PostgreSQL (127.0.0.1:54329) и relay `http://127.0.0.1:8766`, сертификаты и сеть не трогает. Откроется клиент AETHER: вкладка «Регистрация» — создай аккаунт (и второй — для собеседника, в другом браузере/профиле).
2. В AEGIS справа: адрес `http://127.0.0.1:8766`, имя, пароль, собеседник → «Войти в AETHER». Кнопка «Создать аккаунт ↗» открывает регистрацию на указанном сервере.
3. Остановка: `AETHER-LAN\Stop AETHER LAN.cmd`. Аккаунты и сообщения хранятся в `%LOCALAPPDATA%\AETHER-LAN`.

### Чат с другими компьютерами локальной сети

`AETHER-LAN\Start AETHER LAN.cmd` — relay дополнительно слушает `https://<IP этого ПК>:8443` с собственным тестовым сертификатом (90 дней). Windows может спросить разрешение брандмауэра для python.exe — разреши для «Частных сетей». На этом компьютере ничего в доверенные сертификаты не добавляется. На **других** компьютерах один раз импортируй `%LOCALAPPDATA%\AETHER-LAN\tls\root.cer` в «Доверенные корневые центры сертификации» и указывай адрес из `%LOCALAPPDATA%\AETHER-LAN\connection.json`. На этом ПК AEGIS по-прежнему подключается к `http://127.0.0.1:8766`.

Комплект можно распаковать в папку с русскими буквами: PostgreSQL сам использует короткий путь или копию в `%ProgramData%\AEGIS-runtime`.

## Обновление со старой версии

Просто запусти новый `Start AEGIS.cmd`. Если на компьютере уже работает другая копия/версия AEGIS, лаунчер спросит: «Остановить её и запустить 0.7.0?». Данные сохраняются. Чужие программы на порту 8765 лаунчер не трогает — он скажет, какая программа занимает порт.

## Что есть в интерфейсе

- **Обзор / Мониторинг** — реальные CPU, RAM, GPU, сеть, диски, процессы, TCP-соединения. Графики с осями и подсказкой при наведении. Если датчик недоступен (в VM нет температур, GPU) — так и написано, числа не подставляются. Сверху появляется баннер, если связи с агентом нет или данные устарели.
- **Лаборатория** — пять настоящих тестов (CPU, RAM, GPU, DISK, NET) с параметрами, кнопкой «Стоп» и живым графиком нагрузки. Рулетка — необязательный случайный выбор.
- **Синий экран** — кнопка «Показать синий экран» в Лаборатории (или «Синий экран / питание» слева). Это демонстрация: Windows не падает. Выход — Esc или кнопка на экране. Настоящее выключение Windows — отдельная функция с вводом слова ВЫКЛЮЧИТЬ и 45 секундами на отмену.
- **СКУД и камеры** — не подключены: реального оборудования нет, фиктивных событий AEGIS не показывает.

## Если «ничего не работает»

1. Открой `Diagnose AEGIS.cmd` и прочитай первые строки: какая версия отвечает и совпадает ли она с этой папкой.
2. Окно интерфейса должно быть открыто по адресу `http://127.0.0.1:8765` **на той же Windows**, где запущен агент (localhost песочницы и основной Windows — разные компьютеры).
3. `index.html`, открытый как файл, — это не программа: интерфейс сам об этом скажет.
