# Запуск AEGIS SOC v0.6.0

Архив релиза содержит две папки: **FullProject** — весь проект с готовым приложением, relay и исходниками; **PostgreSQL** — только отдельный сервер PostgreSQL и схема базы AETHER.

Ниже команды для PowerShell из корня распакованного архива. Можно просто открыть соответствующий `.cmd` двойным кликом.

## Полный проект в Windows Sandbox

```powershell
& '.\FullProject\Start Sandbox.cmd'
```

Откроется гостевая Windows. В ней автоматически запустятся AEGIS, PostgreSQL AETHER и настоящий relay. Интерфейс AEGIS откроется в отдельном окне Edge. .NET SDK, Python и PostgreSQL на основной Windows устанавливать не требуется.

## Только PostgreSQL для демонстрации

```powershell
& '.\PostgreSQL\Start Database Sandbox.cmd'
```

Этот вариант не запускает AEGIS или relay. Откроется консоль PostgreSQL с таблицами оригинального AETHER. Подробные команды находятся в **PostgreSQL/ЗАПУСК.md**.

Windows Sandbox поддерживает один экземпляр одновременно. Выберите полный проект или отдельную базу для новой сессии. При закрытии гостевой Windows её рабочие данные удаляются.

## Повторный запуск компонентов внутри уже открытой песочницы

На рабочем столе гостя доступны ярлыки. Те же действия через PowerShell внутри гостевой Windows:

```powershell
& "$env:USERPROFILE\AEGIS-kit\AEGIS\Start AEGIS.cmd"
& "$env:USERPROFILE\AEGIS-kit\AETHER-LAN\Start AETHER LAN.cmd"
& "$env:USERPROFILE\AEGIS-kit\AETHER-LAN\Stop AETHER LAN.cmd"
```

AEGIS: **http://127.0.0.1:8765**. Relay на этой машине: **http://127.0.0.1:8766**. Адрес HTTPS текущего гостя находится в **FullProject/RunData/connection.json** после запуска. Пароль чата вводится при входе и не хранится открытым текстом. Для чистой базы тестовые аккаунты создаются через страницу relay.

Нужны Windows x64 с уже доступной Windows Sandbox и около 8 ГБ свободной RAM для полного проекта. Комплект работает без скачивания зависимостей во время запуска. Исходники AEGIS находятся в **Source/AEGIS**, оригинальный relay — в **AETHER-LAN/relay**. Оригинальный репозиторий AETHER не изменялся.
