# Готовый релиз

Скачайте **AEGIS-v0.6.0-windows-x64.zip** на [странице релиза v0.6.0](https://github.com/romantic52/testik/releases/tag/v0.6.0). После распаковки в нём две папки:

- **FullProject** — готовые AEGIS и AETHER relay, все зависимости, исходники и результаты проверок. Чёрно-белый интерфейс.
- **PostgreSQL** — только переносимый PostgreSQL с исходной схемой AETHER, без приложения, relay и приватных данных.

В каждой папке есть **ЗАПУСК.md** с командами PowerShell и SQL. Для полного проекта откройте **FullProject/Start Sandbox.cmd**; для базы отдельно — **PostgreSQL/Start Database Sandbox.cmd**. Все компоненты запускаются в Windows Sandbox.

В Git хранятся исходники и сценарии подготовки/запуска. Большие готовые бинарники .NET, Python и PostgreSQL находятся в ZIP-активе релиза, поэтому папки из исходного checkout не являются готовой установкой. Не запускайте проверки приложения на основной Windows, если хотите сохранить изоляцию: используйте готовый архив и песочницу.
