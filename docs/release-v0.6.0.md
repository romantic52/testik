# AEGIS SOC v0.6.0

Релиз содержит чёрно-белый интерфейс AEGIS, исправления запуска и встроенного AETHER, а также самостоятельный комплект PostgreSQL для демонстрации базы.

## Изменения

- Все разделы, графики, чат и лаборатория используют нейтральные цвета. Подписи секторов рулетки работают при строгой CSP.
- Поля WebSocket-телеметрии сериализуются так же, как REST API, поэтому реальные показания и процессы отображаются в UI.
- В известных виртуальных средах нулевая недоступная температура CPU не выдаётся за реальный датчик. Настоящие ненулевые показания сохраняются.
- Встроенный AETHER не дублирует отправку; состояние relay обновляется при переподключении и выходе.
- Готовый Windows backend включает .NET. Запуск проверяет готовность API и открывает отдельное окно Edge.
- Сценарии relay корректно останавливают оба процесса HTTP/HTTPS, включая старый формат записи PowerShell.
- Папка PostgreSQL запускает только базу на 127.0.0.1:54331, импортирует исходную схему AETHER и открывает консоль с готовыми SQL-запросами. Приватные данные и SQLite туда не включены.

## Проверка

78 автоматических тестов backend пройдены в Windows Sandbox. В предыдущей полной проверке выполнены все пять режимов лаборатории, отмена нагрузки, два реальных E2E-клиента, переподключение, TLS, SQLite, отчёты и режим Windows Service. Обновлённая тема проверена на всех 11 разделах; EXE версии 0.6.0.0 и самостоятельный PostgreSQL повторно проверены. Подтверждены 16 пустых таблиц, повторный запуск, остановка, сохранность учебной записи и доступ только через loopback.

Физические датчики и физическая GPU пользователя, доступ с другого устройства за NAT и отдельная Windows 11 не подтверждены. Готовые исходники AETHER используются без изменений; оригинальный репозиторий AETHER не изменяется и не получает коммитов этого релиза.
