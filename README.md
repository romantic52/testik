# AEGIS SOC

HTML-прототип корпоративной системы мониторинга безопасности для курсового проекта с интеграцией AETHER.chat.

## Реализовано
- SOC dashboard: риск, события, активы и состояние сервисов;
- очередь инцидентов и карточка расследования;
- СКУД, камеры, активы и отчёты;
- встроенная панель AETHER.chat;
- отдельный `AetherAdapter` для будущего подключения реального relay/API;
- кнопка **CRASH SYSTEM** — безопасная демонстрация: фейковый fullscreen BSOD и имитация выключенного экрана;
- адаптивная вёрстка.

> Кнопка CRASH SYSTEM не выключает и не перезагружает реальный компьютер. Браузерная версия только имитирует сбой.

## AETHER.chat
Файл `aether.js` отделяет UI от транспорта. В demo-режиме сообщения остаются локальными. Для настоящей интеграции нужно подключить relay/API проекта `romantic52/AETHER.chat` и выполнять клиентское E2E-шифрование до отправки на relay.

## Запуск

```bash
python -m http.server 8080
```

Открыть: `http://localhost:8080`
